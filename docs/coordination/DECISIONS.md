## 什么算决定，谁来记

**判断标准：**如果明天一个新 session 只读这些文件，在不知道这件事的情况下会做出不同选择，那它就是一个决定。不确定时按 `unconfirmed` 记。

**谁记：**在哪个 session 里说的，就由那个 session 在同一轮、动手之前记下。隐含的决定也算。推翻旧决定要写新的一行并注明替换了哪一行，旧行永远不改。用一次 shell 追加（`>>`）写入。
